# 嵌字小工具 / Manga Bubble Typesetter

一个**单文件、零依赖、纯浏览器**的漫画嵌字工具。打开 `index.html` 就能用，不需要安装任何东西，图片不上传、不出本机。

> A single-file, zero-dependency, browser-only lettering tool for comics / manga.
> No install, no server, no upload — everything runs locally.

---

## 为什么做这个

给漫画/条漫加对白气泡，传统做法是开 PS / CSP 一个个画椭圆、调尾巴、对面部。一页五分钟，六十页一整天。

这个工具把重复劳动压掉：**批量导入 → 摆气泡 → 一键打包导出**，剩下的时间用来微调。

## 功能

### 批量
- 一次导入多张图，左侧缩略图列表
- 缩略图**拖动排序**，顺序即成品顺序
- **页码按顺序自动编号**：已完成页从 1 开始，未完成页接着往后排（第 6 张开始就是 6、7、8…）
- 标记为**特殊页**（封面/扉页/后记）的显示「特」，**不占页码**，导出时命名为 `special-N.png`
- 「未做 / 已完成」两栏切换

### 气泡
| 样式 | 用途 |
|---|---|
| 圆滑 | 普通对白 |
| 星形 | 感叹、强烈情绪（尖角数与内凹可调，带随机抖动） |
| 颤音 | 小声、发抖（外围放射短线，密度/长度可调） |
| 软边 | 心里话、回忆 |
| 方框 | 系统提示、旁白 |

每个气泡可调：**字号 / 每行字数 / 左右留白 / 上下留白 / 填充色 / 描边色 / 不透明度 / 描边粗细**。

**尾巴**：两个根部固定点 + 尖端，都能拖；根部锚定在**真实轮廓**上，星形这类不规则形状也不会飘。描边在根部留缺口，**尾巴与气泡之间不会出现多余的横线**。

### 拟声 / 环境音
独立元素，**不带气泡**，与"说话"视觉分离：
- 可拖、可缩放（四角手柄）、可旋转（顶部手柄）
- 字色 / 描边色 / 描边粗细 / 柔光（复杂背景用）
- 可选括号：`（ ）` / `「 」`

### 导出
- 「导出当前页」——单张 PNG，原尺寸
- 「导出全部」——**打包 zip**，按页码命名（浏览器不允许一次下载几十个文件）
- 「选择导出文件夹」——支持 File System Access API 的浏览器可直接写入指定目录

### 界面
- 配色自定义（主背景 / 面板 / 左侧栏 / 强调色 / 面板宽度）
- **本地图片当壁纸**（不透明度 / 模糊 / 深色遮罩）
- **快捷键全可改**，见下表
- 所有设置存 `localStorage`，下次打开还在

## 快捷键

| 操作 | 默认 |
|---|---|
| 标记完成 | `D` |
| 下一张 | `→` |
| 上一张 | `←` |
| 加气泡 | `B` |
| 加拟声 | `S` |
| 删除选中 | `Delete` |
| 导出当前页 | `Ctrl+S` |
| 导出全部 | `Ctrl+Shift+S` |
| 复制选中气泡 | `Ctrl+D` |
| 打开设置 | `F2` |

全部可在 **⚙ → 快捷键** 里点框重设；点框后按 `Esc` 即可设为**无**（关闭该快捷键）。

## 使用

```text
1. 打开 index.html（或访问 GitHub Pages 地址）
2. 「导入」选一组图
3. 左侧点第一张 → 「＋ 加气泡」→ 在画面上点位置
4. 右侧改字、选样式、拖绿点调尾巴
5. 「导出全部」拿 zip
```

## 兼容性

- **推荐**：Edge / Chrome（支持选目录导出、壁纸）
- **可用**：Firefox / Safari（除"选择导出文件夹"外都能用）

## 目录

```
index.html    全部代码（HTML + CSS + JS，约 40KB）
README.md
LICENSE
```

没有构建步骤，没有 npm，没有 CDN。

## 已知限制

- 不支持竖排文字（计划中）
- 没有撤销栈（用 `Ctrl+D` 复制气泡做备份是临时方案）
- 没有把工程保存成文件——**刷新会丢失当前排版**，推荐先导出
